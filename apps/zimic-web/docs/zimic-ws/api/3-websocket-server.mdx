# `WebSocketServer`

A typed WebSocket server attached to an existing Node.js HTTP or HTTPS server, based on the `WebSocketServer` of the [`ws`](https://github.com/websockets/ws) package. Available in Node.js from `@zimic/ws/server`.

A server accepts connections to every path of its schema, so the clients it receives are typed with the messages of all paths. These clients are on the `'server'` [side](/docs/zimic-ws/api/2-websocket-client.mdx#constructor), so they send server messages and receive client messages.

```ts
import { createServer } from 'node:http';
import { WebSocketSchema } from '@zimic/ws';
import { WebSocketServer } from '@zimic/ws/server';

type Schema = WebSocketSchema<{ '/': { message: { type: 'message'; data: { text: string } } } }>;

const httpServer = createServer();
const server = new WebSocketServer<Schema>({ httpServer });

server.addEventListener('connection', (client) => {
  client.addEventListener('message', (event) => {
    client.send(event.data);
  });
});

httpServer.listen(3000, '127.0.0.1');
await server.open();
```

## `constructor()`

Creates a new `WebSocketServer` instance. The server does not handle connections until [`server.open()`](#serveropen) is called.

```ts
new WebSocketServer<Schema>(options);
```

**Arguments**:

1. **options**: `WebSocketServerOptions`
   - **httpServer**: `http.Server | https.Server`

     The HTTP or HTTPS server whose WebSocket upgrades the server handles.

**Type arguments**:

1. **Schema**: `WebSocketSchema`

   The [WebSocket schema](/docs/zimic-ws/guides/1-schemas.md) of the service.

**Related**:

- [Guides - Using schemas with servers](/docs/zimic-ws/guides/1-schemas.md#using-schemas-with-servers)

## `server.open()`

Starts handling WebSocket connections on the HTTP or HTTPS server. If the HTTP or HTTPS server is not listening yet, the method waits until it starts listening. If the WebSocket server is already open, the method returns without reopening it.

```ts
server.open();
server.open(options);
```

**Arguments**:

1. **options**: `WebSocketServerOpenOptions | undefined`
   - **timeout**: `number | undefined` (default `60000`)

     The maximum time, in milliseconds, to wait for the HTTP or HTTPS server to start listening.

**Returns**: `Promise<void>`

The promise rejects with a [`WebSocketOpenTimeoutError`](/docs/zimic-ws/api/2-websocket-client.mdx#websocketopentimeouterror) if the HTTP or HTTPS server does not start listening before the timeout.

## `server.close()`

Closes the connected clients and stops handling WebSocket connections. The HTTP or HTTPS server is not closed. If the server was not opened or is already closed, the method returns without throwing.

```ts
server.close();
server.close(options);
```

**Arguments**:

1. **options**: `WebSocketServerCloseOptions | undefined`
   - **timeout**: `number | undefined` (default `60000`)

     The maximum time, in milliseconds, to wait for the server to close.

**Returns**: `Promise<void>`

The promise rejects with a [`WebSocketCloseTimeoutError`](/docs/zimic-ws/api/2-websocket-client.mdx#websocketclosetimeouterror) if the server does not close before the timeout.

## `server.addEventListener()`

Adds a listener for a server event. Listeners added before [`server.open()`](#serveropen) are applied when the server opens. Inside the listener, `this` is the server.

```ts
server.addEventListener(type, listener);
```

**Arguments**:

1. **type**: `'listening' | 'connection' | 'error' | 'close'`

   The type of the event.

2. **listener**: `WebSocketServer.EventListener<Schema, Type>`

   The function to call when the event happens. Its parameters depend on the event type:

   | Type | Parameters |
   | --- | --- |
   | `listening` | None |
   | `connection` | `client`: a [`WebSocketClient`](/docs/zimic-ws/api/2-websocket-client.mdx) on the `'server'` side, typed with the messages of all paths; `request`: `http.IncomingMessage` |
   | `error` | `error`: `Error` |
   | `close` | None |

```ts
server.addEventListener('connection', (client, request) => {
  console.log(request.url);

  client.send(JSON.stringify({ type: 'message', data: { text: 'Welcome!' } }));
});
```

**Related**:

- [`ws` `WebSocketServer` events](https://github.com/websockets/ws/blob/master/doc/ws.md#class-websocketserver)

## `server.removeEventListener()`

Removes a listener added with [`server.addEventListener()`](#serveraddeventlistener).

```ts
server.removeEventListener(type, listener);
```

**Arguments**:

1. **type**: `'listening' | 'connection' | 'error' | 'close'`

   The type of the event.

2. **listener**: `WebSocketServer.EventListener<Schema, Type>`

   The listener to remove.

## `server.emit()`

Emits a server event, calling its listeners with the given parameters. If the server is not open, the listeners added with [`server.addEventListener()`](#serveraddeventlistener) are called directly.

```ts
server.emit(type, ...parameters);
```

**Arguments**:

1. **type**: `'listening' | 'connection' | 'error' | 'close'`

   The type of the event.

2. **parameters**: `WebSocketServer.EventListenerParameters<Schema>[Type]`

   The parameters of the event, as received by [listeners](#serveraddeventlistener) of its type.

## `server.isOpen`

Whether the WebSocket server is open and its HTTP or HTTPS server is listening.

**Type**: `boolean`

## `server.baseURL`

The base URL of the server, such as `ws://127.0.0.1:3000`. Throws an error if the server is not open.

**Type**: `string`

## `server.protocol`

The protocol of the server: `wss` for HTTPS servers and `ws` for HTTP servers.

**Type**: `'ws' | 'wss'`

## `server.hostname`

The hostname of the HTTP or HTTPS server, or `undefined` if it listens on a pipe or Unix socket. Throws an error if the server is not open.

**Type**: `string | undefined`

## `server.port`

The port of the HTTP or HTTPS server, or `undefined` if it listens on a pipe or Unix socket. Throws an error if the server is not open.

**Type**: `number | undefined`
